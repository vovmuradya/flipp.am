# 📱 КАК ЗАПУСТИТЬ НА РЕАЛЬНОМ ANDROID ТЕЛЕФОНЕ

## Шаг 1: Настрой телефон (1 минута)

1. **Включи режим разработчика:**
   - Открой **Настройки** → **О телефоне**
   - Найди **Номер сборки** (Build Number)
   - Тапай на него **7 раз подряд**
   - Появится сообщение "Вы стали разработчиком!"

2. **Включи отладку по USB:**
   - Вернись в **Настройки**
   - Найди **Для разработчиков** (Developer Options)
   - Включи **Отладку по USB** (USB Debugging)

3. **Подключи телефон к компьютеру:**
   - USB кабель
   - На телефоне появится запрос "Разрешить отладку?" → **Разрешить**

## Шаг 2: Запусти приложение

```bash
# Проверь что телефон виден
cd /home/vov/flipp-am/mobile-app
flutter devices

# Должно показать что-то типа:
# Android SDK built for arm64 • emulator-5554 • android-arm64
# ИЛИ
# SM-G991B • 1234567890ABCDEF • android-arm64 • Android 13 (API 33)

# Запусти приложение
flutter run
```

## Шаг 3: Дождись установки

- Приложение скомпилируется (~2-3 минуты в первый раз)
- Автоматически установится на телефон
- Запустится как обычное приложение!

## 🔥 Hot Reload

Пока приложение запущено, ты можешь менять код:
1. Отредактируй файл в VS Code
2. Сохрани (Ctrl+S)
3. В терминале нажми **R**
4. Изменения мгновенно появятся на телефоне!

## 🎨 Все новые экраны доступны:

**Нажми на 🔍 (Search):**
- Полнотекстовый поиск
- Кнопка фильтров справа
- Фильтры: цена, год, регион, Copart и т.д.

**Нажми на ➕ (центральная кнопка):**
- Vehicle Listing - создать объявление
- Parts Listing - запчасти
- Import from Copart - импорт с аукциона
- Quick Sell - быстрая продажа

**Нажми на 👤 (Profile):**
- My Listings - мои объявления
- My Auctions - мои аукционы
- Calculator - калькулятор импорта
- Notifications - настройки уведомлений
