## 📱 Вариант 1: НА РЕАЛЬНОМ ТЕЛЕФОНЕ (ЛУЧШИЙ!) 

### Шаг 1: Установи инструменты (1 минута)
```bash
cd mobile-app
./QUICK_START.sh
```

### Шаг 2: Настрой телефон (2 минуты)
1. На телефоне: **Настройки** → **О телефоне**
2. Тапай **7 раз** на "Номер сборки"
3. **Настройки** → **Для разработчиков** → Включи **"USB Debugging"**
4. Подключи телефон USB кабелем
5. На телефоне разреши отладку (всплывет окно)

### Шаг 3: Запусти!
```bash
flutter devices  # Проверь что телефон виден
flutter run      # Установит и запустит на телефоне!
```

**🎉 Готово! Приложение запустится на твоем телефоне как родное!**

## 💻 Вариант 2: ANDROID ЭМУЛЯТОР (виртуальный телефон)

### Установи Android Studio:
```bash
# Скачай
wget https://redirector.gvt1.com/edgedl/android/studio/ide-zips/2024.2.1.11/android-studio-2024.2.1.11-linux.tar.gz

# Распакуй
tar -xzf android-studio-*.tar.gz

# Запусти
cd android-studio/bin
./studio.sh
```

### В Android Studio:
1. Tools → Device Manager → Create Device
2. Выбери **Pixel 6** → Next
3. Скачай **Android 13** → Next → Finish
4. Запусти эмулятор (зеленая кнопка ▶️)

### Запусти приложение:
```bash
cd mobile-app
flutter run
```

**На экране появится виртуальный телефон с твоим приложением!**

## ❓ ВОПРОСЫ?

**Q: У меня WSL, телефон подключится?**
A: Да! USB работает через WSL2. Просто подключи кабелем.

**Q: Можно без телефона и эмулятора?**
A: Можно `flutter run -d linux` но это будет десктопное окно, не мобильное.

**Q: Сколько весит Android Studio?**
A: ~3GB. Если много, используй реальный телефон!

**Q: Телефон не определяется?**
A: `adb devices` - должен показать твой телефон. Если нет - перезапусти adb: `adb kill-server && adb start-server`
